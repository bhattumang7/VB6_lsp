; ------------------------------------------------------------
; Time — the Time intrinsic is a valid primary expression
; anywhere Date is, including as a bare call argument. It is
; consumed as the intrinsic token (no named node), with no ERROR.
; ------------------------------------------------------------

==================

; ------------------------------------------------------------

Function named Name assigns its return value
